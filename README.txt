WEBSITE OUR CLASS — PHIÊN BẢN SANG TRỌNG

CÁCH SỬ DỤNG
1. Giải nén thư mục website_lop_sang_trong.
2. Mở thư mục bằng Visual Studio Code.
3. Thay ảnh trong thư mục images theo hướng dẫn ở images/README.txt.
4. Mở index.html bằng Chrome để xem website.
5. Khi cập nhật GitHub, tải toàn bộ 4 file HTML, style.css, script.js và thư mục images lên repository, giữ nguyên cấu trúc thư mục.

CẤU TRÚC
- index.html       : Trang chủ
- gioithieu.html   : Giới thiệu lớp
- hoatdong.html    : Hoạt động của lớp
- thuvien.html     : Thư viện ảnh có phóng to/chuyển ảnh
- style.css        : Giao diện dùng chung
- script.js        : Menu di động, hiệu ứng và thư viện ảnh
- images/          : Ảnh của lớp

CẦN CHỈNH SỬA
Tìm các cụm như OUR CLASS, NIÊN KHÓA 20__ — 20__, nội dung giới thiệu và mô tả hoạt động trong file HTML để thay bằng thông tin thật.
Website dùng Google Fonts để tải kiểu chữ Playfair Display và DM Sans; nếu không có Internet, trình duyệt sẽ dùng font dự phòng.
